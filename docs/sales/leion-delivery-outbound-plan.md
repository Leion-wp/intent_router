# Leion Delivery Founder Outbound Plan

## Goal

Create enough pipeline-qualified conversations to close the first two paid pilots.

## Target Segment

- agencies shipping client work on GitHub
- software factories with repeated PR and release handling
- small engineering teams with visible review friction

## Message

Reduce repetitive delivery work without removing human approval.

## Core Offer To Pitch

- `Leion Delivery Founding Pilot`
- `4 500 EUR` setup
- `4-week` scope
- up to `5 repos`
- three governed delivery workflows

## Contact List Fields

- company
- owner name
- role
- segment
- repos or engineering team size
- GitHub workflow evidence
- likely pain
- last touch
- next action
- owner
- date

## Outreach Sequence

### Touch 1

- short intro
- one workflow pain
- one sentence on governed AI delivery
- CTA for a short call

### Touch 2

- send a concrete workflow example
- attach one proof asset or demo screenshot

### Touch 3

- ask a direct qualification question about issue to PR, PR fixes, or release gates

### Touch 4

- close the loop politely
- ask whether timing or fit is the blocker

## Qualification Rule

Advance only if the buyer has:

- recurring GitHub delivery work
- approval or governance sensitivity
- a repo group they can pilot on
- an owner who can drive the workflow change

## Weekly Cadence

- Monday: refresh target list and message
- Tuesday to Thursday: outbound and demos
- Friday: proposals, proof updates, and follow-ups
