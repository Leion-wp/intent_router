# Leion Delivery Pilot Onboarding Checklist

## Customer Inputs Needed Before Kickoff

- one named owner
- one target organization
- one target repo group
- one agreed pilot workflow sequence
- one approval policy owner

## Technical Prerequisites

- GitHub repositories identified
- local repo access confirmed
- `git` configured
- `gh` installed and authenticated where needed
- VS Code available for the initial runtime path
- preferred AI provider decided
- BYO AI key available if AI flows are enabled

## Delivery Setup

- install `Leion Roots`
- import the `Leion Delivery` workflow pack
- configure repo path, test command, and security command defaults
- define approval checkpoints
- define who can approve

## Pilot Success Criteria To Lock Before Start

- one `Issue -> PR` run on a real repo
- one `PR Review -> Fix / Improve` run on a real PR
- one `Release / QA / Security Gate` run on a real repo
- one repeatable demo path the customer can replay

## Exit Assets

- workflow pack configured for the customer
- run history and proof exports
- operating notes
- next-step subscription proposal
