# Leion Delivery Pricing

## Pricing Principles

- do not price by seat in V1
- price by operational value: org, repos, governed workflows, support
- require `BYO AI keys` or explicit cost pass-through
- keep enterprise controls as upsell, not as blockers to early revenue

## Open-core

### Leion Roots

- price: `free`
- includes:
  - VS Code extension
  - local builder
  - local runtime
  - open workflow JSON files

## Sales-led Offer

### Leion Delivery Founding Pilot

- price: `4 500 EUR` setup
- post-pilot: `1 000 EUR / month`
- scope:
  - 1 organization
  - up to 5 repos
  - 3 delivery workflows
  - onboarding
  - adaptation to one operating model
  - 4-week pilot with explicit success criteria

## Public Packaging After 2 To 3 Paid Pilots

### Starter

- price: `699 EUR / month`
- includes:
  - 1 organization
  - up to 5 repos
  - delivery workflow pack
  - hosted webhook and cron relay
  - basic run history and audit
  - email support
  - BYO AI keys

### Growth

- price: `1 499 EUR / month`
- includes:
  - up to 20 repos
  - shared policy packs
  - centralized run history
  - usage analytics
  - priority support
  - monthly onboarding session

### Enterprise

- price: `from 5 000 EUR / month` plus setup
- includes:
  - private runner
  - SSO
  - audit export
  - SLA
  - security review support
  - dedicated support

## Billing Rules

- default currency: `EUR`
- default billing: monthly
- founding pilot is always fixed-fee setup first
- no bundled unlimited LLM consumption in V1
